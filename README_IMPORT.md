# Import guide

Unzip this package at the repository root that already contains:
- `main.py`
- `app/`

## Target result
```text
project_root/
├─ main.py
├─ app/
├─ AGENTS.md
└─ _codex/
```

## Important
- `AGENTS.md` must stay at repository root.
- `_codex/` stays separate from `app/`.
- Do not move `_codex/` into `app/`.
- Open Codex from `project_root/`, not from inside `app/`.
