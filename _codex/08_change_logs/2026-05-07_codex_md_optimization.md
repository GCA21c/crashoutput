# Codex MD optimization

## What changed
- 새 세션이 먼저 읽는 핵심 문서를 최신 Ver 1.0 방향으로 압축했다.
- 오래된 v095 기준 handoff/current state 내용을 main baseline과 향후 개발 방향 기준으로 갱신했다.
- `AGENTS.md`에 `_codex/08_change_logs/`는 필요 시만 읽는 토큰 절약 기준을 추가했다.

## Why
- `_codex/` 문서가 누적되며 새 세션 초기 토큰 사용량과 혼란 가능성이 커졌다.
- 앞으로의 중심 작업은 시험모드별 dummy/injury criteria 확장, report valuation, template export 구축이다.

## Scope
- 코드 로직은 변경하지 않았다.
- 상세 change log는 보관하고, 기본 읽기 대상에서 제외하는 정책만 명확히 했다.
